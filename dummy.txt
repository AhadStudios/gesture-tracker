What the application does
-------------------------
This is a real-time hand gesture recognition tool built with MediaPipe and OpenCV.
It uses a webcam to detect 21 hand landmarks and runs two lightweight TFLite models:

1. KeyPointClassifier — static hand signs: Open, Close, Pointer, OK
2. PointHistoryClassifier — finger motion: Stop, Clockwise, Counter Clockwise, Move

Processing pipeline (app.py, about 82% of the Python code):
  camera capture
  -> MediaPipe Hands landmark detection
  -> relative / normalized keypoints
  -> optional CSV logging for dataset collection
  -> classification
  -> on-screen overlay (bounding box, landmarks, FPS, labels)

The classifier modules load a TFLite interpreter (ai-edge-litert, with TensorFlow as fallback),
run inference, and return the predicted class. A small utility measures rolling FPS.

Origin and maintenance
----------------------
The project is based on the public Kazuhito00 MediaPipe hand-gesture sample.
This fork updates the environment so it runs on current systems:
- MediaPipe pinned to 0.10.9
- TensorFlow Lite runtime replaced with ai-edge-litert
- Verified on Python 3.11 (Windows)

Structure
---------
The live app is self-contained. Drawing, preprocessing, and logging live in app.py.
Models sit in separate modules. Training notebooks are optional and are not required
to run the webcam demo. There is no backend service, test suite, or extra config layer.

Summary
-------
This is a compact computer-vision demo: webcam loop plus two classifiers,
approximately 500 lines of Python. Suitable as a working prototype for
real-time hand-sign and finger-motion recognition.
